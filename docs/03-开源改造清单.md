## P1 必改 —— LLM provider 抽象（约 1 周）

**关键发现**：不是只有 `core/qwen_client.py` 一处，**实际有 3 个并行的 Qwen HTTP 客户端**（QwenClient + `intent/embedder.py` + `tool_simulator.py::QwenGenerator`），后两者各自硬编码 `dashscope.aliyuncs.com` endpoint。

**分两阶段**：
- **阶段一（1-2 天）**：定义 `LLMProvider` Protocol（`async generate(...)`），`QwenClient` 降级为实现之一，~7 个实例化点改工厂注入。**好消息**：`generate` 签名稳定，响应解析走 OpenAI 兼容格式，OpenAI/Anthropic 容易接。
- **阶段二（3-5 天，真正成本）**：
  - 合并 3 个并行 HTTP 客户端
  - 配置层 + DB 列改名：`QwenConfig`→`LLMConfig`、`db/runtime_config.py` 的 `qwen_model` 列、前端 `update_tool_result_mode("preset"/"qwen")` 枚举
  - `m11_session_cost.py` 硬编码 ¥ 人民币定价表 → 可配置 + 币种泛化
  - `enable_thinking`（Qwen/DashScope 专属）收进 provider extra-args
  - 品牌字样清理（~33 文件含 `qwen`/`Qwen`/`dashscope`）

## P2 加分项 —— 生态对接（开源后再做）

- 接 **OpenTelemetry** 出口（Langfuse/mcp-eval 都走 OTEL，不接进不了主流 trace 生态）
- AgentDB 抽成 `SessionSource` 接口 + 一个 **OTLP 标准 trace adapter** 作为示例（取代 Pixcake 线报协议）
- `core/notifier.py` 钉钉 → 抽 `Notifier` 接口 + Slack webhook 实现（海外友好）

## 可直接保留的资产（开源价值所在）

- ✅ **MCP 六组全部 20 个工具**（除命名和一处错误词典）
- ✅ ~11 个通用指标（M1/M2/M3/M4/M7/M8a/M10/M11/M12/M13/M15）
- ✅ `validators.py`（JSON schema 校验，100% 通用）
- ✅ `core/case_runner.py` + `mock_script_builder.py`（0 处图像关键词）
- ✅ 前端 8 个通用工作区（tool_version/prompt_version/prompt_editor/batch_report/knowledge_workspace/release_board 等）
- ✅ 四层 mock 框架（L0-L2 通用保留；L3 在 MCP proxy 模式下弃用，见 `06`）
- ✅ CI 无人值守评测 + 发版看板 + 回归判定（`regression_verdict.py` PASS_STATES 严格口径）

## 🔴 最大风险

**AgentDB 的 `ai.sessions_*` schema 是 Pixcake 线报协议**（`runs[].tools[]`、`dispatched` 回执、`SERVER_TOOLS` 白名单），不是通用 agent trace。

开源时**必须定位为「示例 adapter」而非核心**，否则别人接不进去，第一印象就崩。

## 双轨路线图

| 策略 | 工作量 | 交付物 | 适用 |
|------|--------|--------|------|
| **A. 最小开源版（推荐先发）** | **约 2 周** | 通用核心 + MCP 六组 + AgentTransport + MCP Proxy + 录制泛化；Pixcake 专有部分（tool_simulator/preference/retouch/agentdb 实现）**不开源**或单独放 `adapters/pixcake/` 默认不启用 | 快速占位、验证社区反馈、避免过度投入 |
| B. 完整通用化版 | +1-2 周 | schema 清洗（agent-agnostic）+ provider 阶段二 + OTLP adapter + 前端重写 + 着陆页 | 确定做严肃开源项目时 |

**建议先走 A**：最大差异化（用例积累飞轮 + MCP proxy + 工具层测试）在最小版里都保留；最大坑（tool_simulator 81KB / agentdb 私有协议）正好「先不开源」绕掉。等社区反馈再投入做 B。

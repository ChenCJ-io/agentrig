# 01. 迁移资产清单与边界

## 1. 分类规则

每个 AgentScope 文件进入 AgentRig 前必须标记为以下一类：

- **COPY**：没有业务依赖，可直接复用；
- **EXTRACT**：视觉和交互可复用，需拆除 API、Context、Fixture 和路由；
- **REIMPLEMENT**：交互目标相同，但必须使用 AgentRig 契约重写控制层；
- **EXCLUDE**：内部业务、鉴权、数据或品牌，禁止进入开源代码。

## 2. COPY：可直接复用

| AgentScope 来源 | AgentRig 目标 | 处理 |
|---|---|---|
| `frontend/app/components/ui/badge.tsx` | `web/app/components/ui/badge.tsx` | 已同源，合并差异 |
| `frontend/app/components/ui/button.tsx` | `web/app/components/ui/button.tsx` | 已同源，合并差异 |
| `frontend/app/components/ui/panel.tsx` | `web/app/components/ui/panel.tsx` | 已同源，合并差异 |
| `frontend/app/components/ui/stat-card.tsx` | `web/app/components/ui/stat-card.tsx` | 已同源，合并差异 |
| `frontend/app/components/content/markdown-content.*` | `web/app/components/content/` | 移除 AgentScope Deep Link 规则后复用 |
| Playwright 双桌面 Project 配置 | `web/playwright.config.ts` | 保留 AgentRig 端口与启动命令 |
| `tests/e2e/route-manifest.ts` 的数据结构 | `web/e2e/route-manifest.ts` | 重建 AgentRig 路由清单 |

COPY 不等于盲目覆盖。每个文件先做三方比较：AgentScope 来源、AgentRig 当前文件、迁移结果。

## 3. EXTRACT：抽取展示组件

### 3.1 评测主链

| AgentScope 组件 | AgentRig 组件 | 必须拆除的耦合 |
|---|---|---|
| `EvaluationSummaryBand` | `evaluation/run-summary-band.tsx` | AgentScope Fixture 和 Channel Label |
| `BatchRunSummary` | `evaluation/run-summary.tsx` | Batch 命名、Pixcake 版本字段 |
| `BatchDetailTabs` | `evaluation/run-detail-tabs.tsx` | AgentScope URL 拼接 |
| `BatchExecutionMonitor` | `evaluation/run-progress.tsx` | `BatchRun` Mock Type |
| `BatchCellList` / `BatchMatrix` | `evaluation/cell-matrix.tsx` | App/Tool/Channel 固定维度 |
| `CellDetailPage` | `evaluation/cell-detail/` | API Query、Fixture、Report Route |
| `ReportPage` / `ReportTabs` | `evaluation/report/` | AgentScope Report DTO |
| `WizardChrome` | `evaluation/run-wizard/wizard-chrome.tsx` | AgentScope Draft LocalStorage |
| Case Catalog/Editor/Review | `cases/` | Pixcake Scenario、Image/Project 字段 |

抽取时保留 DOM 层级、CSS 类名、焦点顺序和响应式规则，将 Query、Mutation、SSE 和 Navigate 放回 Page Controller。

### 3.2 对话与助手

| AgentScope 能力 | AgentRig 用途 | 复用边界 |
|---|---|---|
| Conversation 三栏几何 | Target 连接调试 | 只复用 Session Rail、Message List、Evidence Rail |
| Message Bubble / Markdown | 智能评测助手 | 消息角色改为 user/assistant/system/tool |
| Composer | 调试与评测助手 | 去除图像编辑特有操作 |
| Context Menu | Target/Profile/Plan/Run 上下文 | 只保留 AgentRig 真实可选项 |

智能评测助手不复用 AgentScope 的业务 Prompt，也不恢复 Rule Assistant。

### 3.3 资产

| AgentScope 能力 | AgentRig 对应 | 处理 |
|---|---|---|
| Assets Master/Detail | Assets Overview | EXTRACT 几何与筛选交互 |
| Tool Samples | Tool Result Samples | 使用 AgentRig `Sample` DTO |
| Tool Schema Editor | Target Tool Contract | 改接 Capability/Schema |
| Prompt Versions | 暂无等价对象 | EXCLUDE，等后端有通用 Prompt Asset 再引入 |
| Knowledge / Preference | 暂无等价对象 | EXCLUDE |

## 4. REIMPLEMENT：必须使用 AgentRig 重写

- `AppShell` 数据控制层：使用 Target/Project/Auth Token，不使用 `AgentScopeContext`；
- `RuntimeTargetControl`：显示 Target、Version、Driver、Profile，不显示 Pixcake Channel；
- 评测 Query/Mutation：调用 AgentRig `/api/*`，不复制 AgentScope `evaluation.ts`；
- SSE/Polling：使用 AgentRig Run/Assistant 事件契约；
- 权限与登录：保留 AgentRig Bearer Token/Deployment 配置；
- 路由 Controller：保留 `/targets/:targetId/...` 语义；
- Empty/Error/Partial 判定：以 AgentRig API 返回为准，禁止静默降级到 Mock。

## 5. EXCLUDE：禁止进入 AgentRig

- `context/agent-scope.tsx`；
- `api/auth.ts` 中的钉钉和内部 Bootstrap 逻辑；
- `api/evoto.ts`、`pages/evoto/`；
- `mocks/` 中的内部业务数据；
- Pixcake Agent 名称、Logo、人物头像、图片和背景图；
- AgentDB、图片编辑、项目状态、Preference 等专有字段；
- 内部域名、内部 Header、真实用户信息、Access Token；
- 只有 AgentScope 后端才能实现的按钮和成功状态。

## 6. 来源与授权门禁

AgentScope 仓库当前未见可直接适用于对外复制的 LICENSE 文件。在复制源码进入 AgentRig 公开历史前，
必须由项目所有者确认开源授权。

每个迁移 PR 记录：

```text
Source repository
Source commit
Source file/component
Migration class: COPY | EXTRACT | REIMPLEMENT
Private-data scan result
Visual baseline frame
```

授权未确认时，可先在本地分支做组件边界验证，不推入公开分支。

## 7. 迁移前扫描项

至少扫描以下类型：

```text
Pixcake / Evoto / DingTalk / agent-scope.tsx
*.hiclaw.io / internal API URL
Authorization / Cookie / access token
user id / mobile / email / avatar
fixture / mock / hard-coded success
image project / preference / AgentDB
```

扫描结果和例外说明必须作为 PR 附件。

## 8. 资产清单完成标准

- 每个候选组件都有唯一分类；
- COPY/EXTRACT 有来源 Commit 与对应截图；
- EXTRACT 组件不 Import AgentScope API、Context 和 Mock Type；
- EXCLUDE 关键字不存在于 AgentRig 打包产物；
- 开源授权结论已有文字记录。

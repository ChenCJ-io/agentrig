## 推荐发版策略的理由

**后端 alpha 先发** 而非等前端：
- 开源讲究 early and often，先占「MCP-first + 用例积累飞轮」这个空旷生态位
- 核心差异化全在后端（MCP proxy + 工具层测试 + 飞轮基础设施），alpha 就能让人看到
- 前端重写 2-3 周是最大单项成本，不该阻塞后端发版
- alpha 阶段可用 README + MCP 工具文档 + 一个 demo（CC 给陌生 MCP agent 写用例跑通）先吸引早期用户

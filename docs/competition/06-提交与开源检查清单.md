# 提交与开源检查清单

## 初赛（截止 2026-08-16，以官网最新通知为准）

- [x] 项目名称约 20 字，清楚表达 Agent Infra 定位。
- [x] 作品简介不超过 500 字，覆盖问题、方案、创新、开放价值和进展。
- [x] 方案 PPT 内容覆盖场景、三 Agent、Skill、MCP、验证、安全与开源计划。
- [x] Agent Identity 清单说明身份、能力边界和协同关系。
- [x] AgentTeams 映射不是概念描述，存在可运行 Manager/Worker 和协作证据。
- [ ] 在报名系统填写团队真实信息并完成最终提交。
- [ ] 用最终公开仓库链接替换本机路径和分支说明。

- [x] README、运行入口、依赖、示例配置和本机部署说明。
- [x] AgentTeams 版本固定、三角色资源和确定性 package builder。
- [x] 成功链路真实运行证据。
- [x] 失败链路 TestCase 与演示脚本。
- [x] 权限、密钥、审批、取消、幂等、降级和审计说明。
- [x] MIT License、CONTRIBUTING、SECURITY、CODE_OF_CONDUCT、CHANGELOG。
- [ ] 录制 6—8 分钟 Demo 视频并检查无凭据、Cookie 或内网地址泄露。
- [x] 输出最终运行截图、脱敏机器证据和一页式运行报告。
- [ ] 推送 V2 分支、创建 Release/Tag，并在干净机器验证压缩包。

## 凭据与隐私

- [x] `.env.local-agentteams`、数据库、runtime token、Cookie 均被 Git 忽略。
- [x] 配置文件只提交 `env:`/Secret 引用和无敏感示例。
- [ ] 录制/公开前更换比赛专用模型 Key。
- [ ] 提交前扫描 Git 历史、构建产物、截图和日志中的敏感值。
- [ ] 不提交 lassist 内部业务代码；只提交 AgentRig 的公开协议适配与示例。

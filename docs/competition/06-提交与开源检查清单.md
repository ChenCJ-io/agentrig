## 最终验证命令

先在干净 checkout 生成并严格校验公开、无模型的基础提交证据：

```bash
scripts/reference_demo.sh all --profile reference-ci
scripts/reference_demo.sh validate-evidence --require-clean-source
```

提交归档至少保留该次 CI 的 `release-evidence.json`、`reference-evidence.json`、
`reference-evidence.md`、`reference-runs.json`、`public-config.json`、`sbom.cdx.json`、两个锁文件
快照和 `SHA256SUMS`。其中 `components.agentteams = null` 只证明公开确定性基线；真实三 Agent
协作仍以脱敏 Matrix/Invocation 证据和现场复核为准。

完整工程校验：

```bash
scripts/local_demo.sh setup
scripts/local_demo.sh verify
uv run ruff check src tests examples scripts
uv run mypy src/agentrig
uv run pytest
AGENTRIG_TEST_PIXCAKE_URL=http://127.0.0.1:8000 \
  uv run pytest -q tests/compat/test_agentscope_pixcake_live.py -vv
npm run typecheck --prefix web
npm run build --prefix web
```

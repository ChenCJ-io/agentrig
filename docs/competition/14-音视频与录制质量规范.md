## 画面为什么不能再抖

旧视频对静态截图使用缩放或平移，小字边缘会持续移动并被编码器反复量化。正式版只允许三类镜头：

1. 固定 1920×1080 产品截图；
2. 真实录屏中的静态区域与必要点击；
3. 固定标题/架构卡。

不使用自动跟随鼠标、Ken Burns、数字防抖或为了“有动感”持续缩放。需要强调时用短暂色块、下划线或
镜头硬切到局部固定画面。

## 旁白质量

机械女声和过高音调会削弱技术内容的可信度。优先由真人按场景录制；无法真人录制时使用自然中文男声，
每段单独合成和响度归一化。英文术语、SHA、Run ID 不逐字符朗读，只念其语义并让画面承载完整值。

人工听感检查：

- 耳机试听：齿音、爆音、呼吸和英文断句；
- 笔记本扬声器：人声是否刺耳、背景是否淹没；
- 1.25 倍播放：仍能理解术语与数字；
- 场景切换：不截断句尾，不用音乐掩盖等待。

## 字幕策略

- 每行约 20—24 个中文字符，一条最多两行；
- 字幕跟随语义而不是逐字跳动；
- 术语保持 `Run`、`Cell`、`Attempt`、`Sample`、`Manifest`；
- 底部避开产品状态栏和操作按钮；
- 白字、半透明深色底、足够描边；同时交付独立 SRT。

## 真实录屏规范

- 浏览器与 Codex 统一 100% 缩放，录屏前锁定窗口位置；
- 关闭通知、悬浮客服、自动更新和桌面小组件；
- 不显示 `.env`、API Key、Cookie、请求头、邮箱、个人路径和 lassist 私有资产；
- 等待阶段可以剪掉，但前后必须是同一 Session/Plan/Run；
- 每个正式 ID 先写入 ledger，再进入字幕和旁白；
- 彩排截图可以进 PPT 说明“已验证”，不能剪成“正式现场”。

## 自动验收

构建后检查：

- MP4 1920×1080、30 fps、H.264 High、yuv420p；
- AAC 48 kHz stereo；
- SRT 时间单调、无重叠、结尾不超过视频；
- PPTX/PDF 页数和画布一致；
- 场景源文件都存在，媒体 JSON 记录 SHA-256；
- 从每个场景抽帧确认没有几何漂移、破图和字幕截断；
- 全片响度与 true peak 达标。

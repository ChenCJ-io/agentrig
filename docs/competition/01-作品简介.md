# 初赛作品简介

## 项目名称

**AgentRig：多 Agent 低副作用评测与回归平台**

## 提交正文（500 字以内）

Prompt、工具描述或模型升级后，团队往往只看到一次回答“似乎正确”，却无法证明工具选择与参数是否正确，也不敢反复触发图片、支付、发信等昂贵工具。

AgentRig 以 AgentTeams 为协同基点编排三个职能 Agent——Manager 负责目标理解与计划、Curator 生成受控模拟结果、Judge 做独立语义裁决；确定性 Rule/Fixture 是低成本快速路径。平台保留被测 Agent 的真实推理、协议、Session 与工具决策，只把工具结果治理为 Fixture、人工审核 Sample 或受控 Real Tool，再以冻结身份、Manifest、独立 Attempt、Timeline 构成可审计证据链。开发者经项目 Skill 与 MCP 治理回归，普通用户用自然语言规划、经人工确认执行。

公开 EditFlow 场景已验证：Before 2/5 提升到 Candidate 5/5，六 Case 矩阵 30/30，真实 MCP 采样后回放 5/5 且零真实工具调用，Web 助手 3/3。项目 MIT 开源，并以 lassist 验证可接入真实生产 Agent。

## 评委应记住的三点

- 真实的是 Agent 决策；受控的是高成本或高风险工具副作用。
- Codex 与 Web 助手可以规划不同方案；统一的是资产、确认边界和证据合同。
- `completed ≠ pass`；每个结论都能回到 Prompt SHA、Manifest、Cell、Attempt 和事件。

## 2. 作品简介（500 字以内）

以下正文去除空白后 431 个字符：

> 企业 AI Agent 上线后常遇到三个难题：业务行为难以稳定复现、工具调用结果不可控、模型裁决缺少可追溯证据。AgentRig 提供一套 MCP 原生、多 Agent 协作的回归评测基础设施。用户只需用自然语言描述测试目标，AgentTeams Manager 自动查询用例与运行资产，生成可预览、必须确认的评测计划；Simulation Curator 仅依据冻结上下文生成受控工具结果；Evidence Judge 对脱敏的完整运行证据进行独立裁决并引用真实事件 ID。确定性 Rule、不可变快照、幂等状态机和角色隔离 MCP 共同防止越权、伪造结论与重复执行。项目已真实连接 lassist/Pixcake Agent，完成计划、确认、工具调用、结果模拟、证据裁决和失败诊断闭环，并提供 SQLite 本机一键 Demo、AgentTeams 部署包、11 个可复用 Skill、开放接口、测试与安全文档。AgentRig 不绑定单一业务 Agent，可迁移到客服、研发、运维等需要持续验证的企业智能体场景。

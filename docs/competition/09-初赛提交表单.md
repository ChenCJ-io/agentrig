# 初赛提交表单填写稿

## 项目名称

AgentRig：真实 Agent 的低副作用回归与证据基础设施

## 赛道

Agent Infra 新智基座

## 一句话介绍

保留 Agent 的真实模型决策，控制高成本工具副作用，把 Prompt 和工具行为变化转成可复用、可审计的
Case、Run、Cell、Attempt、Sample 与发布证据。

## 项目简介（可直接粘贴，与 01-作品简介.md 提交正文一致，462 字）

Prompt、工具描述或模型升级后，团队往往只看到一次回答“似乎正确”，却无法证明工具选择与参数是否正确，也不敢反复触发图片、支付、发信等昂贵工具。

AgentRig 保留被测 Agent 的真实推理、协议、Session 与工具决策，只把工具结果治理为 Fixture、人工审核 Sample、Simulator 或受控 Real Tool；再以冻结身份、Manifest、Cell、独立 Attempt、Timeline 与 Rule/Judge 构成可审计证据链。开发者在 Codex 中经项目 Skill 与 MCP 完成风险分析、用例治理与 Before/Candidate 对比；普通用户在 Web 助手中用自然语言规划，经人工确认后执行。

公开 EditFlow 场景已验证：Before 2/5 提升到 Candidate 5/5，六 Case 矩阵 30/30，真实 MCP 采样后回放 5/5 且零真实工具调用，Web 助手 3/3。项目 MIT 开源，并以 lassist 验证可接入真实生产 Agent。

## 核心创新

1. **真实决策与工具副作用解耦**：不是绕过 Agent 的纯 Mock；模型、协议、Session、工具选择仍真实。
2. **身份与证据冻结**：Prompt SHA、Manifest、Case Snapshot、Cell/Attempt 让 Before/Candidate 可比较。
3. **工具结果资产治理**：真实事件显式生成 Draft Sample，人类审核后低成本回放。
4. **双入口统一事实内核**：Codex 负责开发治理，Web 助手服务普通用户；方案可不同，证据合同一致。
5. **可解释失败**：区分 behavior、case、evaluator、infra，避免把 Fixture miss 冒充模型回归。

## Agent / Skill / MCP

- 被测 Agent：公开 EditFlow，Agno + `deepseek-v4-flash`，五个 external-execution 修图工具；
- 项目 Skill：`prompt-regression-governance`，规定冻结、Case 审计、Before/Candidate、门槛和报告；
- AgentRig MCP：Target/Case/Profile/Sample/Run/Cell/Attempt 的读写与执行；人工批准不暴露给 MCP；
- Web Assistant：OpenAI-compatible DeepSeek Provider，自然语言规划并由 Core 确认、提交和执行；
- 可选 AgentTeams：Manager/Curator/Judge，用于复杂规划、动态模拟和语义裁决，不是本次 Rule 场景必需。

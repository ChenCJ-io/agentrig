# AgentRig 设计文档

> 项目设计决策记录：定位、竞品、执行模型、协议适配、前端、CC skill 包。
> 面向使用者与贡献者——理解 AgentRig 怎么设计、为什么这么设计、怎么扩展。

## 这是什么项目

**AgentRig** = 给 AI 编码工具（Claude Code / Codex）用的 agent 回归测试台。

编码工具通过 MCP 调用 AgentRig：看懂本次改动 → 发现/构建测试场景 → 跑场景（四层 mock 回放）→ 机判 + 回写结论 → 持续累积回归用例库。

## 关键决策一句话索引

- **命名**：`AgentRig`（避开阿里 AgentScope）
- **产品愿景**：让 agent 回归用例随开发自动积累——CC 看代码 + 读历史数据生成用例，开发时跑增量、发版时跑全量，用例库越用越厚（**数据飞轮 = 真护城河**）
- **技术定位**：MCP 时代的「工具层测试台」（vs Langfuse 对话层观测），agent-native testing（AI 测 AI）
- **主接入**：MCP proxy/aggregator（agent 配一处 mcp config）
- **加分资产**：开箱即用的 CC 测试 skill 包（教 CC 用 MCP 工具做测试的方法论，竞品没有，见 `08`）
